Notas para exponer

Lo que quedó hecho es una aplicación que se abre en el navegador. Cada muestra de chip tiene hilos de ensayo en Tx, Rx o PLL. Un hilo reúne pasos con notas, mediciones y evidencias. Los pasos pueden estar aprobados, fallidos o en progreso; el estado del hilo refleja ese avance. También se puede buscar, filtrar y exportar la lista de hilos. Los datos y los cambios quedan guardados. Para seguir: Una vez visto el resultado, paso a cómo se fue construyendo.

Notas para exponer

En la muestra A0 abro el hilo de ganancia. Tiene tres pasos: preparar el banco, medir y revisar el resultado. La preparación está aprobada, la medición está en progreso y la revisión sigue pendiente. Desde cada paso puedo agregar notas, cargar una medición y adjuntar un archivo o enlace. El hilo sigue En progreso mientras haya pendientes; si algún paso falla, queda Fallido. Los indicadores permiten abrir todos los hilos de cada estado. Para seguir: Ese recorrido deja datos y archivos; ahora muestro dónde quedan y para qué sirve cada uno.

# Frontend

JavaScript nativo con módulos; sin framework ni build. api.js centraliza fetch y
CSRF; ui.js maneja diálogos; app.js coordina el estado. El número de revisión
impide aplicar respuestas tardías de otra selección. Una escritura confirmada
no debe mostrarse como fallida si después falla el refresco.
Mantener labels, foco visible, confirmación destructiva y mensajes de error.
El CSV representa exclusivamente la macro y filtro visibles.
